Under the hood

A ledger you can audit.

Balances are never just a number that gets overwritten. Every movement writes a transaction and signed ledger entries with the running balance attached.

1
Lock, validate, postBoth accounts are locked with SELECT … FOR UPDATE, then funds are checked before anything is written.
2
Double-entry transfersTransfers produce two signed entries that sum to zero; deposits record the bank's external side.
3
Reversible, never deletedOperators reverse transactions by posting the mirror image. The original stays in the ledger.
4
Settings live in MySQLRates, limits and maintenance mode are rows in settings — editable without a redeploy.

Four commands

From clone to banking in a minute.

Docker runs MySQL; the seed script creates the schema, settings and demo data.

terminal 
# 1 · start MySQL
docker compose up -d

# 2 · python environment
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt

# 3 · configuration + schema + demo data
cp .env.example .env
python -m scripts.seed

# 4 · run both apps
uvicorn app.main:app --reload          # :8000 customers
uvicorn admin_app.main:app --port 8001 # :8001 operators
